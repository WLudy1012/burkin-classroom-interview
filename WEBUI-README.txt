布尔金课堂访谈 · Windows 本机 WebUI

1. 解压完整 ZIP，双击“启动WebUI.cmd”。便携包内已包含 Node.js，不需要安装其他服务。
2. 浏览器会自动打开；默认地址是 http://127.0.0.1:4173 。如果端口被占用，以启动窗口中显示的地址为准。
3. 首次使用在“模型设置”填写 Base URL 和百炼 API Key，再点击“开始访谈”。支持麦克风、文字提问、人物动作、场景自动切换和音色设置。
4. 关闭启动窗口或按 Ctrl+C 可停止 WebUI。

所有模型调用由这台 Windows 电脑发起，不需要部署远程服务。网页仅允许这台电脑访问。API Key 只保存在本次启动进程的内存中，关闭后需重新填写；Base URL、音色 ID、语速和待完成的复刻音色 ID 保存到当前 Windows 用户配置目录。请勿直接用 file:// 打开 index.html。
